The Key Location Tracker provides a condensed way of tracking important locations and access to specific parts of the map. Using the "warp to start" feature, the player should be able to quickly navigate to any area or location that they have tracked.

The Visual Tracker takes a more intuitive approach, allowing the user to label the entrances on a copy of the in-game overworld. It will even draw connections for locations that have multiple points of entry - but it is more cumbersome to use when trying to do speedruns.

The DX version of the Visual Tracker is more feature-rich, allowing the user to change the state of certain regions such as the animal companion regions, or change the seasons in Oracle of Seasons, which can also be randomized.

Jangler's Oracles Randomizer and links to various forks can be found at https://github.com/jangler/oracles-randomizer
